# infra-plugins

The rules for working in this repository are in `CLAUDE.md`. Read it first.

This file exists because Codex does not read `CLAUDE.md`, and the plugins here ship Codex
manifests as well as Claude ones. It holds a pointer rather than a second copy of the rules
on purpose: three copies of a single filing rule in another repository had already drifted
into three different answers, and a rule that disagrees with itself is worse than a rule
somebody has to follow a link to reach.

How to build, structure and release a plugin is in `CONTRIBUTING.md`.
